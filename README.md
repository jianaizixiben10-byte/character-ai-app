# 🐹 オリジナルキャラ生成AIアプリ

## 🌐 公開URL
https://character-ai-app-e6d4i9azxgq8w9lqh2zuxz.streamlit.app/

## 📌 概要
AIでオリジナルキャラクターを生成し、そのキャラクターと会話できるWebアプリです。  
今回は、モルモットの「ちゃむ」をベースに、癒し系キャラクターAIとして制作しました。

## 🐹 キャラクター
- 名前：ちゃむ
- 性別：男の子
- 性格：食いしん坊・温厚
- 口癖：〜ちゃむ
- 苦手なもの：爪切り

## 🛠 使用技術
- Python
- Streamlit
- OpenAI API
- GitHub
- Streamlit Cloud

## ✨ 主な機能
- オリジナルキャラクター生成
- キャラクターとのAI会話
- 会話履歴表示
- 会話リセット
- キャラクター画像表示
- タブ切り替えUI
- APIキーのSecrets管理

## 💡 工夫した点
- キャラクター設定を会話に反映できるようにしました。
- 語尾に「〜ちゃむ」をつけ、キャラクター性を強くしました。
- Streamlitのタブ機能を使い、プロフィール・生成・会話を分けました。
- GitHubとStreamlit Cloudを使ってWeb公開しました。
- APIキーをSecretsで管理し、安全性にも配慮しました。
